# Home Renovation API

The NestJS GraphQL API and report worker for the Home Renovation platform. It handles authentication, jobs and their history, real-time chat over GraphQL subscriptions, and PDF report generation in a background worker.

See the [repository README](../README.md) for setup, the API overview and design decisions.

## Tech Stack

- **Framework:** NestJS, TypeScript (ESM)
- **API:** GraphQL with Apollo Server, subscriptions over `graphql-ws`
- **Database:** PostgreSQL with TypeORM (migrations and seed data)
- **Queue and pub/sub:** Redis, BullMQ, `graphql-redis-subscriptions`
- **Auth and validation:** JWT, class-validator, Zod
- **Reports:** PDFKit, generated by the worker
- **Tooling:** Vitest, oxlint, Prettier

## Getting Started

The database and Redis must be running. From the repository root:

    pnpm infra:up

Then, from this package, apply migrations, load the demo data and start the API:

    pnpm migration:run
    pnpm seed
    pnpm start:dev

The GraphQL endpoint is available at http://localhost:4000/graphql.

To process report jobs, run the worker in a second terminal (after `start:dev`, which builds `dist/`):

    pnpm worker:dev

## Scripts

| Command | What it does |
| --- | --- |
| `pnpm start:dev` | API with reload, on http://localhost:4000/graphql |
| `pnpm start:debug` | API with reload and the Node debugger attached |
| `pnpm worker:dev` | Report worker with reload (run `start:dev` first; it builds `dist/`) |
| `pnpm build` | Compile the project to `dist/` |
| `pnpm start:prod` | Run the compiled API |
| `pnpm start:worker` | Run the compiled report worker |
| `pnpm migration:run` | Applies pending migrations |
| `pnpm migration:generate src/database/migrations/<Name>` | Generates a migration from entity changes |
| `pnpm migration:revert` | Reverts the last migration |
| `pnpm migration:show` | Lists migrations and whether they've been applied |
| `pnpm migration:check` | Fails if entities have drifted from the migrations |
| `pnpm seed` | Resets the database to the demo data |
| `pnpm test` | Unit tests (`test:watch` and `test:cov` also available) |
| `pnpm test:e2e` | End-to-end tests (need `pnpm infra:up` from the root) |
| `pnpm lint` | Type-aware linting with oxlint |
| `pnpm format` | Format the code with Prettier |
